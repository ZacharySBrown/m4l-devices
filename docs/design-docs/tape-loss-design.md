## Reference behavior

Lo-fi tape degradation: wow (slow random pitch drift), flutter (fast
twitchy texture), magnetic-hysteresis saturation, 12 EQ models
(VHS/cassette/dictaphone/toy/reel-to-reel), tape dropouts/snags/crinkles.
Should sound musical at noon-noon settings; "struggling machinery" at
extremes. WOW + DRY UNITY produces classic chorus naturally. CPU < 8%
on M1 at 44.1kHz/64-sample vector.
