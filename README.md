# m4l-devices

Max for Live devices for Ableton Live -- the playback and performance layer of the Setforge ecosystem.

For the full ecosystem overview (curation pipeline, live performance, arrangement), see [`../stemforge/SETFORGE.md`](../stemforge/SETFORGE.md).

---

## Devices

### setforge-loader.amxd -- Set Loader (Session View)

Audio effect that loads a set produced by `taste forge-set` into Ableton's session view.

- Reads `set.json` + `manifest.json` (schema 2.1) with relative-path chop WAVs
- Populates clip slots: 4 stem rows (drums / bass / other / vocals) x 8 chop columns
- Dual-song mode for blending two songs simultaneously
- Scene memory: recall stem + chop states per scene
- Curation persistence: edits saved back to manifest

### setforge-grid.amxd -- Launchpad MIDI Bridge

MIDI effect on a dedicated MIDI track that routes Launchpad input/output to the loader.

- Modifier layer: HOLD / MUTE / SOLO / REV / STUT / HALF / DBL / KILL
- Pad color feedback reflecting clip state
- **Requirement:** MIDI track must be armed with Monitor set to In

### setforge-calibrate.amxd -- Validation and Warp Editing

Utility device for validating beat grids and editing warp markers on stems.

### setforge-arranger.amxd -- Arrangement View Loader (Coming Soon)

Loads stems into arrangement view as N-bar padded clips with loop regions.

- Re-anchor workflow: drop locators in Live, device recomputes grid
- **Status:** working in stemforge v0, being ported to this repo

### punch-fx -- Performance FX Suite

Collection of performance-oriented audio effects (stutter, tape stop, filter sweeps).

- **Status:** spec complete, build not started

### tape-loss -- Generation Loss MKII Recreation

Lo-fi tape degradation: wow, flutter, magnetic saturation, tape malfunction, and VHS/cassette EQ profiles. A native DSP recreation of the Chase Bliss Generation Loss MKII pedal.

- **Status:** specification complete, build in progress
- **Spec:** [`specs/tape-loss-spec.md`](specs/tape-loss-spec.md)

## Data Flow

```
taste forge-set my_set.yaml
        │
        ▼
  set.json + manifest.json + chop WAVs
        │
        ▼
  setforge-loader.amxd (session view)
  setforge-grid.amxd   (Launchpad bridge)
```

The device reads `set.json` and `manifest.json` produced by the `taste` repo's `forge-set` command. All chop WAV paths in the manifest are relative, resolved at load time.

## Philosophy

**Spec first.** Every device has a written specification before any patching happens. The spec defines DSP algorithms, signal flow, parameter ranges, UI layout, and build order.

**Understand the DSP.** The goal is to understand and implement the actual signal processing, not approximate a sound. Algorithms are derived from source material where possible.

**Ableton-native.** All parameters are exposed as automatable Live parameters. Devices feel like first-class Live instruments.
