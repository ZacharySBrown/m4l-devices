Basic Performance (Solo Mode)

GestureWhat happens
Tap preset pad (row 5/6)Activate that preset. All stem rows source from it. Held chops migrate at the next launch-quant boundary (hot-swap).
Tap chop pad (rows 1-4)Start playing that chop. Tap again to stop. Tap a different column in the same row to replace.
Hold HOLD + tap chopOne-shot: plays once, doesn't latch.
Double-tap modifierLatch (stays active until tapped again). Single tap is momentary.
HOLD + tap scene padSave current state to that scene slot.
Tap scene padRecall: restores preset, held chops, modifiers, and view mode.
Triple-tap PANIC (side)Stop everything. Reset to solo mode.

Each stem has its own quant — chops snap to the grid naturally:

StemQuantFeel
Drums1/16Instant, tight chops

NEW Per-Row Mode

Each stem row independently sources from its own preset. Drums from song C, bass from song F, vox from song A — all at once. The mashup move.

Entry & Exit

Double-tap SOLO
Enters per-row mode. SOLO pad latches yellow. All rows initially source from the current preset.
Tap SOLO (while latched)
Exits per-row mode. Returns to solo mode. Active preset becomes whatever drums row was sourcing.

Reassigning a Row

Hold any stem pad +
tap a preset pad
That stem row reassigns to the tapped preset. Clips reload for just that stem. If a chop was held, it migrates to the new preset at the next quant boundary.
The leftmost pad (col 1) of each stem row shows the source-preset color, so you can see at a glance which song each row is playing from.

Example: cross-song mashup

Activate "Electric Relaxation"
→
Double-tap SOLO
→
Tap drums D3 (hold it)
→
Tap "Rebirth of Slick" preset
→
Release D3

Now drums play Rebirth's kit while bass/other/vox still play Electric Relaxation. Tap bass chops — hear both songs layered.

NEW Staging & Pre-Loading

Stage two songs for dual-song mode while you're still performing. The audio engine pre-loads both in the background so the view flip is instant.

The Staging Gesture

Hold deck-setup
right side, position 2
Side button lights bright white. You're now in staging mode.
Tap row 5 preset
while deck-setup held
Deck X staged. That pad flashes preset color ↔ white. Pre-load begins.
Tap row 6 preset
while deck-setup held
Deck Y staged. That pad flashes preset color ↔ soft blue. Pre-load begins.
Release deck-setup
Exit staging mode. Staged pads keep flashing. Pre-load continues in background.
Wait ~5 seconds after staging for pre-load to complete before entering dual-song mode. If you enter immediately, there may be a brief load delay.

Entry & Exit

Hold top-right side btn
Peek into dual-song mode. Release to snap back to your previous view.
Double-tap top-right
Latch into dual-song mode. Tap once more to exit.
Triple-tap PANIC
Emergency exit: stops all audio, returns to solo mode.

What's hidden in dual-song view

Modifiers (row 7) and scenes (row 8) are replaced by song Y stems. To use modifiers or scenes, exit dual-song first.

Preset banks are hidden. To swap a song, exit → restage → re-enter.

Control view is still accessible via the top-left side button.

The move this was built for: tap drums-X chop N and drums-Y chop N at the same time. Both fire at the next 1/16 boundary. Kick-on-kick, locked tight. Layer two completely different drum patterns from two different songs.

Saving Your Work

Send these messages to the device (via Max message box or the device UI):

CommandWhat it does
saveFull save: reads all clip markers from Live, writes manifest + set.json back to disk. Round-trips your edits.
syncReads clip state from Live into memory (no disk write). Use to preview before saving.
nudge 0.05Nudge active preset's downbeat by +50ms. Negative values work too.
set_bpm 98.5Set active preset's BPM.
The manifest files are the source of truth. save overwrites them. If you want to preserve the original taste output, back up the manifest directory first.

Audio Routing

The device creates 8 audio tracks in Live:

TrackPurpose
sf-drumsDeck X drums (solo/per-row/dual-song rows 1)
sf-bassDeck X bass
sf-otherDeck X other
sf-voxDeck X vox
sf-drums-yDeck Y drums (dual-song row 5)
sf-bass-yDeck Y bass
sf-other-yDeck Y other
sf-vox-yDeck Y vox

You can add Live effects to any of these tracks. FX target "drums" hits both sf-drums and sf-drums-y in dual-song mode.
