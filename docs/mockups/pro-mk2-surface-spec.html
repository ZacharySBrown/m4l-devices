From docs/specs/pro-mk2-surface.md · note/CC numbers + SysEx pulled from the working launchpad-surface-mk2.js. Top/Bottom = presets (CC) · Left = stem-assign · Right = punch-FX + utility · grid = 8 stems × 8 chops.

Surface — buttons · function · MIDI

▲ TOP = BANK A (CC 91–98) · ▼ BOTTOM = BANK B (CC 1–8) · ◀ LEFT = STEM-ASSIGN
▶ RIGHT = punch-FX (red, grouped top): Beat Repeat · Stutter · Mute Slicer · Octave Down — then PANIC · scene ◀▶ · 1 free slot (19)
Deck A rows (chops 81–58) Deck B / extended (48–11) cells = grid note · note=(9-row)*10+col

Stem-assign gesture

1
Hold a left stem-assign button → enters ASSIGNING (button pulses white, grid row dims).
2
Tap a preset (top = Bank A / bottom = Bank B) → that row sources that stem from the preset (all its chops).
3
Row + left button re-color to the source preset's color → back to IDLE.
Release without a preset = cancel · re-press same = reset row to default. Max 1 stem per type per bank.

Punch-FX gesture (hold → press pad)

1
Hold a punch button (REPEAT / STUTTER / SLICER / OCT−) → grid enters FX-APPLY mode (chop-trigger overridden).
2
Press a pad → the effect hits that pad's clip/stem; the pad's pressure (poly-aftertouch) sets the 0–1 amount. Multiple pads = multiple stems, independent pressure.
3
Release pad = effect off for that stem · release button = back to chop-triggering.
Pressure comes from the grid pad, not the round button. Needs poly-AT (0xA0) handling + per-stem punch-fx routing.

Per-source LED palette (shared with companion app)

7-bit RGB for MK2: r7 = round(r8*127/255). Grid row + its left button + its preset button all wear the source color.
