## Reference behavior

Pressure-sensitive punch-in performance effects inspired by the
Teenage Engineering EP-133 K.O. II. Four effects in series: Beat
Repeat (tempo-synced buffer loop), Stutter (short chaotic retrigger),
Mute Slicer (rhythmic amplitude gate), Octave Down (granular or
varispeed pitch drop). Each driven by a momentary trigger + continuous
pressure value. Should feel snappy and gestural — instant on, soft
release, exp curves for expression. CPU < 5% on M1 at 48kHz/64-sample.
